# Week 6 Assignment: SQL Joins and Relationships

## Overview
This assignment demonstrates how to retrieve related information from multiple tables using SQL JOIN operations in the MySQL Classic Models database.

## Learning Objectives
- Understand INNER JOIN, LEFT JOIN, and RIGHT JOIN.
- Combine data from related database tables.
- Apply SQL joins using matching columns.
- Retrieve specific information from multiple tables.

## Questions Completed

### Question 1: INNER JOIN – Employees and Offices
Retrieved employee first names, last names, email addresses, and office codes.

### Question 2: LEFT JOIN – Products and Product Lines
Retrieved product names, vendors, and product lines.

### Question 3: RIGHT JOIN – Customers and Orders
Retrieved the first 10 orders, including order dates, shipped dates, statuses, and customer numbers.
